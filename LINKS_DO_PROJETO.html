Banco de dados · Supabase (projeto biomonitor, São Paulo)

  • Painel do projeto https://supabase.com/dashboard/project/cuquscwkzbnckznebyeq Entre com sua conta pessoal do GitHub (petersonsouza81-rgb).
  • Usuários (criar logins da equipe) https://supabase.com/dashboard/project/cuquscwkzbnckznebyeq/auth/users Add user > Create new user, marcando Auto Confirm User. Depois o acesso à usina é dado na tabela acessos.
  • Tabelas (empresas, usinas, sedes, vistorias, acessos) https://supabase.com/dashboard/project/cuquscwkzbnckznebyeq/editor
  • SQL Editor https://supabase.com/dashboard/project/cuquscwkzbnckznebyeq/sql/new
  • Fotos das vistorias (pasta privada) https://supabase.com/dashboard/project/cuquscwkzbnckznebyeq/storage/files/buckets/fotos
  • Endereços de login (link de "esqueci minha senha") https://supabase.com/dashboard/project/cuquscwkzbnckznebyeq/auth/url-configuration
  • Chaves da API https://supabase.com/dashboard/project/cuquscwkzbnckznebyeq/settings/api-keys Só a chave publishable vai no site. A secret nunca sai do painel.
  • Plano gratuito: o projeto pausa depois de cerca de uma semana sem uso. Os dados não se perdem; para voltar, abra o painel e clique em Restore. Confira antes de uma demonstração.
